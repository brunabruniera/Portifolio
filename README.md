# Relatório de aprendizagem

**Bruna Bernardi Bruniera — 1F**

Para fazer o portfólio, usei o site que eu já tinha feito e só fiz algumas mudanças para ele ficar melhor no celular e para que ficasse mais parecido com o da imagem proposta pois o meu estava bem diferente. Então testei como ele ficava em uma tela menor e vi que algumas partes ficavam meio desorganizadas e outras acabavam ficando cortadas. Então fui mudando algumas coisas no CSS para que, no formato de celular, nada ficasse cortado pela metade. Também modifiquei algumas cores para deixar o site mais bonito.

Algumas partes que ficavam lado a lado no computador não cabiam direito no celular, então precisei fazer com que elas ficassem uma embaixo da outra. Também percebi que alguns textos e elementos ficavam muito grandes para o tamanho da tela. Por isso, fui ajustando os tamanhos e os espaços para que tudo ficasse mais organizado e não ficasse tudo apertado.

Depois de fazer as mudanças, fui testando o site novamente no celular para ver se ainda tinha alguma parte cortada ou desorganizada. Quando encontrava algum problema, voltava no CSS e fazia mais alguns ajustes até ficar do jeito que eu queria. A ideia não era mudar o portfólio inteiro, mas adaptar o que eu já tinha feito para funcionar melhor em uma tela menor.

Tentei também adicionar JavaScript para adicionar modo escuro e pesquisa nos projetos, mas foi uma tentativa falha pois não sei totalmente como fazer e ficou bem desconfigurado, então quando aprender mais sobre poderei tentar adicionar de novo.

Para fazer esse projeto usei o **Visual Studio Code**, o **HTML** e o **CSS** para criação do site e o **Claude** para consertar o código que ficava com a indentação errada e a desorganização do CSS.
